# iOS 0.1.3：近7天来源规则

## 使用顺序
选择行业 → 输入关键词 → 查找潜在客户。

- **先筛视频/笔记来源，再筛评论。** 来源必须有可核实的发布时间，处于上海时区今日及前 6 天内，并从确认的最新发布搜索排序中选取。
- 不用评论日期、采集时间、视频 ID 或编辑时间代替来源发布时间。来源日期不明、未来日期、已超过 7 天的内容不进入当前潜客结果；识别不了排序时不回退为热门结果。
- 评论时间的“近7天 / 近30天 / 全部”只是后续评论筛选，不关闭来源门槛。地区、年龄、收藏、关键词和所有任务范围也都遵守同一门槛。
- 旧版记录没有来源发布时间证明，因此不会自动当作合格来源；数据仍保留。菜单“历史备份”用于导出所有旧记录，不代表当前潜客名单。
- 当前结果导出会在点击导出时再检查来源日期。用户主页、评论和意向标签仍需人工核实。

App 仅处理可访问的公开网页；需要登录或验证码时由本人完成，不读取其他 App 登录态。年龄只接受本人核实的主页公开资料，不从头像或昵称推断。
